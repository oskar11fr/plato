# Summarize a book

Write the page a reader opens first: in a few minutes it should tell them what the book is about, what it argues, how it gets there, and which chapter to read for what.

## Structure

Right under the title, write a **TL;DR** of two or three sentences: what the book is about and its main argument or contribution. Then use these sections, leaving out any that don't apply:

- `## The argument`: the book's central thesis or aim, and the main claims it rests on. A few paragraphs, not a chapter-by-chapter retelling.
- `## How the book builds it`: how the chapters fit together: which lay foundations, which develop the core ideas, which apply or extend them. Link the chapters as you mention them. Group chapters where the book does (parts, themes) rather than going through them one by one.
- `## Key concepts`: the concepts that recur across chapters or carry the argument, one per line, each as a wiki link with a one-line definition and the chapter(s) where it matters most.
- `## Where to start`: only if it helps: which chapters to read for which purpose, or which can be skipped.
- `## Open questions`: only if the chapter pages raise some worth following up.

## Accuracy

- Use only what the chapter pages say. Don't add claims about the book from general knowledge; if something important seems missing, say the chapter pages don't cover it.
- Keep the chapter pages' page citations when you repeat a specific claim or number.
- If some chapters aren't summarized yet, cover the rest and say briefly which are missing.

## Style

- Plain, direct sentences.
- Aim for 400 to 800 words.
- No filler such as "this book offers a comprehensive treatment".

## The reader's input

- If the reader named a focus for the book, give it more room.
